# Rule-Base-AI-Python-Chatbot
A simple Rule-Based AI Chatbot built with Python that responds to basic user questions using predefined responses. This project demonstrates Python fundamentals such as dictionaries, functions, loops, conditional statements, string handling, and user input.




🚀 Project Completed: Rule-Based AI Python Chatbot 🤖
I’m excited to share one of my recent Python projects — a Rule-Based AI Chatbot developed using Python.
The chatbot is designed to interact with users and provide predefined responses to basic questions. This project helped me understand how Python can be used to build simple conversational systems using fundamental programming concepts.
🔹 Key Features:
💬 Responds to basic user questions
🧠 Uses a dictionary to store predefined responses
🔄 Uses loops and conditional statements for response matching
🔤 Processes user input using string methods like .lower() and .strip()
⏰ Displays a personalized greeting based on the current time
👋 Allows the user to exit the chatbot using a simple command
🛠️ Technologies & Concepts Used:
Python | Dictionaries | Functions | Loops | Conditional Statements | String Handling | User Input | Date & Time
📚 What I Learned:
While working on this project, I strengthened my understanding of Python fundamentals, functions, dictionaries, loops, user-input handling, and debugging. It also gave me practical experience in converting a simple idea into a working application.
